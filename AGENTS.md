# Инструкции для ИИ-агентов (Claude Code, Codex, Cursor и др.)

Этот файл читается агентом в начале работы с репозиторием. Здесь все, что нужно знать, чтобы вносить изменения и ничего не сломать.

## Что это за проект

«Деканат Next»: рабочий прототип личного кабинета студента для номинации «Вайб-кодинг» конкурса MGIMO AI Challenge (задание «Цифровой деканат будущего»). Кабинет адаптирован под структуру Университета ИТМО, но это концепт, а не официальный сервис. Все данные вымышлены.

Обязательное ядро из задания (не удалять и не ломать):
1. Вход и профиль (ФИО, факультет, направление, курс, группа).
2. Расписание на сегодня и на неделю, аудитория и преподаватель, переносы и отмены.
3. Успеваемость: баллы и зачеты, сессия, общая картина.
4. Заявки и справки онлайн со статусом.
5. Уведомления: объявления деканата, дедлайны, изменения.

Дополнительно: кабинет сотрудника деканата, переписка с деканатом, электронная справка с QR-кодом, калькулятор баллов, выгрузка расписания в календарь, темная тема, установка на телефон (PWA).

## Стек и запуск

- Python 3.12+, FastAPI, Jinja2 (серверный рендеринг), SQLAlchemy 2, SQLite (PostgreSQL через переменную `DATABASE_URL`).
- Пароли: argon2id (`argon2-cffi`). QR: `qrcode` (SVG).
- Фронтенд без сборки: `app/static/css/app.css`, `app/static/js/app.js`. Шрифты Unbounded и Golos Text лежат локально.

```bash
pip install -r requirements.txt -r requirements-dev.txt
uvicorn app.main:app --reload          # http://127.0.0.1:8000
python -m pytest -q                    # все тесты должны проходить
python -m app.seed --reset             # пересоздать демо-базу
```

## Правила, которые нельзя нарушать

1. **Студент видит только свои данные.** Идентификатор студента берется только из серверной сессии (`require_student`), никогда из адреса или формы. Любой запрос к данным студента фильтруется по `student_id` текущего пользователя. Чужая запись: ответ 404, а не 403.
2. **Каждый POST проверяет CSRF-токен** (`check_csrf`) и роль (`require_student` / `require_staff`).
3. **Пароли только в виде хеша argon2id.** Токен сеанса в базе только как SHA-256.
4. **Никаких секретов в репозитории.** Ключи и пароли сервисов только через переменные окружения. Тест `test_no_secrets_in_repository` это проверяет.
5. **Только вымышленные данные.** Не добавлять реальные ФИО, оценки, номера зачеток. Не подключаться к системам вуза.
6. **Не использовать логотип вуза.** На страницах должно быть видно, что это концепт для конкурса.
7. **Время.** "Сейчас" и расписание считаются в часовом поясе вуза (`services/timeutil.py`). Служебные отметки в базе хранятся в UTC.
8. **Шкала баллов** взята из открытого документа ИТМО (edu.itmo.ru/files/23) и закреплена тестом `test_grade_scale_matches_itmo_document`.

## Стиль интерфейса

- Тексты на русском, простые и конкретные, без буквы «ё» и без длинного тире.
- Мобильная версия первая: все сценарии должны работать на ширине 360 px.
- CSP запрещает inline-скрипты и inline-стили: JS только в `app/static/js/`, стили только в `app.css`. Ширины полос задаются атрибутами SVG.
- Цвета и размеры через CSS-переменные в начале `app.css`, есть светлая и темная тема.
- Иконки: `{{ icon('имя') }}` из `static/icons/sprite.svg`.

## Как вносить изменения

1. Прочитать затрагиваемые файлы целиком.
2. Внести изменение и добавить или обновить тест.
3. Запустить `python -m pytest -q` и проверить страницу на ширине 390 px и 1440 px.
4. Обновить `docs/PROCESS.md`, если изменение заметное.
